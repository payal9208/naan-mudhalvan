# 🎬 Movie Recommendation System

A Flask-based movie recommendation system developed using Python. The application recommends movies based on the user's selected genres and predicted ratings.

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- Pickle
- HTML
- CSS
- Recommendation Model

## ✨ Features

- Genre-based movie filtering
- Movie rating prediction
- Top 5 movie recommendations
- Simple web interface
- Flask-based backend
