# 🎬 Movie Recommendation System

A simple Movie Recommendation System built using **Python, Flask, Pandas, and Machine Learning**.

## 📌 About the Project

This project recommends movies based on the **genre selected by the user**.  
The system filters movies according to the selected genre and uses a trained recommendation model to predict ratings and display the top recommended movies.

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- Machine Learning
- HTML
- CSS
- Pickle

## ✨ Features

- 🎬 Genre-based movie recommendations
- ⭐ Predicts movie ratings
- 🔍 Filters movies based on user preference
- 🌐 Simple web interface using Flask
- 📊 Displays top 5 recommended movies

## 📂 Project Files

- `app.py` – Flask application
- `model.py` – Model training
- `data.py` – Data processing
- `clean_data.py` – Data cleaning
- `movies.csv` – Movie dataset
- `ratings.csv` – Ratings dataset
- `style.css` – Website styling

## 🚀 How to Run

1. Install required libraries:
   `pip install flask pandas`

2. Run the application:
   `python app.py`

3. Open the browser and visit:
   `http://127.0.0.1:5000`
